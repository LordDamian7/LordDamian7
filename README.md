#### ⭐ Featured: [MitochronAi Lab](https://github.com/LordDamian7/mitochronai-lab)
An offline-first laboratory system with an AI assistant, **Gaya**, that checks every result against the lab's rules (duty roster, reading windows, cut-offs, formulas, reagent expiry, critical values), drafts reports and holds anything doubtful for a person. Nothing is released without a named chief scientist's approval, and every action is audited.

- Next.js · TypeScript · `node:sqlite` · unit and end-to-end tests · CI
- Signed USB software updates with automatic rollback, for labs without reliable internet
- Written security reviews for each iteration; synthetic data only

#### How I work
- **Rules in code, language in the model.** Anything safety-critical is deterministic, tested code; AI handles drafting and explanation.
- **Tests and reviews first.** Changes go through tests, pull requests and, for security-sensitive work, a written review.
- **AI-assisted, human-directed.** I design and direct the work and build with AI pair-programming (Claude Code), and I'm open about it.
